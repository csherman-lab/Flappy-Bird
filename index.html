Flappy Bird 3D — setup required

This game cannot run by double-clicking the HTML file. You need a local web server.

  1. Open a terminal in this project folder
  2. Run: ./start.sh or python3 -m http.server 8080
  3. Open http://localhost:8080 in your browser
