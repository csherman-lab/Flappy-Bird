# Realistic Flappy Bird

A polished, dependency-free browser remake of Flappy Bird built with HTML,
CSS, and Canvas. The visuals are drawn procedurally in JavaScript, so the game
does not depend on external image assets.

## Highlights

- Realistic feathered bird with layered wing, tail, body, beak, and eye detail.
- Parallax golden-hour environment with clouds, mountains, reeds, sun glow, and
  ambient motes.
- Mossy, weathered pipe obstacles with rounded caps, texture, highlights, and
  shadows.
- Responsive high-DPI canvas rendering for desktop and mobile.
- Keyboard, mouse, and touch controls.
- Pause, game-over, score, best-score persistence, particles, and sound effects.

## Run locally

```bash
npm start
```

Then open `http://localhost:4173`.

No package install is required.

## Controls

- `Space`, `ArrowUp`, click, or tap: flap / restart
- `Esc`: pause / resume

## Verify

```bash
npm run check
```
